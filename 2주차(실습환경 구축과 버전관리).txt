git (버전 관리 시스템)

설치과정
sudo apt install git -y
git config --global user.name "이름"
git config --global user.email "이메일"
git config --global init.defaultBranch main

git config --list: 기본 설정 확인 

git init: 깃이 버전을 관리하는 디렉터리로 초기화
git status : 깃 상태보기 

git add 파일명: 파일 추가
git add .  :수정한 모든 파일 지정
git commit -m "message": 커밋 메시지 추가
git log: 커밋 기록 확인
git log --oneline: 

git switch -d <커밋 해시>: 커밋 변경 / 커밋을 구분할 수 있을 만큼 앞부분만 입력(7자리)
git diff <커밋 해시1> <커밋 해시2>:  커밋 해시2에새로생긴부분 커밋 해시2에서삭제된부분

git switch -c 브랜치이름 : 브랜치 만들기
git switch 브랜치이름: 브랜치 이동
git branch : 현재 브랜치 확인

github
$ gh repo create <레포이름> --public --source=. --remote=origin --push 
▪ <레포이름>
• 생성할GitHub repository 이름
▪--public
• 공개저장소로생성
▪--source=.
• 현재디렉터리를원본으로사용➔현재디렉터리의Git 저장소를GitHub에연결
▪--remote=origin
• 원격저장소이름지정
▪ origin
• 연결된원격저장소에관례적으로사용하는이름
▪--push
• 로컬의커밋을원격저장소에업로드
